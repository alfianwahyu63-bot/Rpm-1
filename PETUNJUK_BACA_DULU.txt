KENAPA SEBELUMNYA TETAP CAMPUR?
Versi master lama menampilkan semua brand GLOBAL. Selain itu Service Worker lama
menyajikan app.js dari cache walaupun Anda sudah upload kode baru. Patch ini
memfilter berdasarkan data minggu terpilih dan memaksa browser membaca versi baru.

CARA PASANG:
1. Backup JSON data RPM terlebih dulu (bila sudah punya sales).
2. Buka repository GitHub yang sedang digunakan oleh Cloudflare Pages RPM.
3. GANTI 3 FILE DI ROOT REPOSITORY (sejajar firebase-config.js):
   index.html, app.js, sw.js
   JANGAN upload ZIP mentah. Jangan buat folder baru.
4. Commit changes. Pastikan Cloudflare Pages sudah berhasil deploy.
5. Buka situs RPM Cloudflare (bukan GitHub lama), refresh halaman 2 kali.
6. Buka menu MASTER PRODUK. Di deskripsi harus ada tulisan FIX WEEK 3.0 AKTIF.
   Jika tulisan ini tidak ada, aplikasi masih memakai kode lama.
7. Minggu 2 hanya merek yang memiliki target/PLU minggu 2;
   Minggu 3 hanya merek yang memiliki target/PLU minggu 3.
8. Bila data lama memang sudah terlanjur tercatat di dua minggu, gunakan tombol
   Hapus Minggu Ini pada Master Produk setelah backup JSON. Ini tidak menghapus
   merek, PLU, QTY atau target minggu lain.

JANGAN TIMPA firebase-config.js. Konfigurasi Firebase Anda tetap.
JANGAN hapus database Firestore dan jangan hapus data Chrome/PWA.
