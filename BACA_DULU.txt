SALESPULSE RPM — FIX TAMPILAN 4.0 (3 November 2026)
=================================================
PENYEBAB HALAMAN MENJADI POLOS
HTML terbaru memanggil style.css dan cloud-sync.css.
Jika CSS itu tidak berada di root website atau belum ter-deploy, tampilan menjadi teks polos.
Kalau app.js juga gagal ditemukan, halaman tidak menjadi interaktif.

PERBAIKAN KALI INI
- style.css + cloud-sync.css sudah DITANAM langsung ke index.html.
- Kode app.js (versi pemisahan minggu FIX WEEK 3.0) DITANAM langsung ke index.html.
- Kode cloud-sync.js juga tertanam di index.html.
- File eksternal tetap tersedia untuk kompatibilitas browser yang masih menyimpan index versi lama.
- Tidak mengubah rumus target, point 50/50, time factor, atau Firebase workspace.

CARA PASANG
1. BACKUP JSON dari dashboard Anda dahulu.
2. Buka repo GitHub yang tersambung ke Cloudflare Pages.
3. Ekstrak paket ZIP ini. Upload ISI paket ke folder root (di samping firebase-config.js).
4. Jangan upload ZIP mentah, jangan taruh file di dalam folder tambahan.
5. PENTING: JANGAN HAPUS / UBAH firebase-config.js yang sudah diisi.
6. Commit changes; tunggu Cloudflare Pages selesai deploy.
7. Buka domain Cloudflare RPM (alamat *.pages.dev), refresh.
8. Cek tulisan "TAMPILAN 4.0" pada label versi Dashboard.
9. Coba pilih Minggu 2 dan Minggu 3; daftar dan target harus berbeda.

JANGAN HAPUS DATA FIRESTORE / STORAGE CHROME.
Belum bisa menjamin data lintas-HP tersinkron jika firebase-config.js
atau aturan keanggotaan Firestore belum benar-benar aktif.

Penting: paket ini sengaja TIDAK menyertakan firebase-config.js,
agar konfigurasi cloud Anda tidak tertimpa data contoh.
